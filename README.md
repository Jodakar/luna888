# 🌙 LUNA888 — ERP-система для бренда «Золотая Луна»

## 📋 Описание
Профессиональная ERP-система для управления товарными остатками, заказами маркетплейсов (Wildberries, Ozon), курьерской доставкой и складским учётом.

## 🎯 Цели
- Централизованное управление остатками на всех складах
- Синхронизация с МойСклад, Wildberries API, Ozon API
- Учёт маркировки (КИЗы Честного Знака)
- Управление доставкой (FBS, DBS, FBO)
- Автоматизация отчётности

## 🏗️ Технологический стек
- Backend: Flask + SQLAlchemy + PostgreSQL
- Frontend: Bootstrap 5 + JavaScript
- Сервер: Ubuntu 22.04, Nginx, Gunicorn
- База: PostgreSQL 14, Redis
- Мониторинг: Telegram-бот, SMTP

## ✅ Реализовано (v1.0)
- Авторизация (email + пароль, восстановление)
- Модуль «Сотрудники» (права, уведомления)
- Модуль «Товары» (остатки, фильтры, поиск, сканер, КИЗы)
- Модуль «Настройки» (API-ключи, SMTP, мониторинг)
- Автосинхронизация с МойСклад (каждые 10 минут)
- 6 складов (Основной, WB FBS, Ozon FBS, DBS, WB FBO, Ozon FBO)
